# Icons

Place PNG icons here before loading the extension:

- `icon16.png` (16×16)
- `icon48.png` (48×48)
- `icon128.png` (128×128)

Any square PNGs work. The `manifest.json` references these three sizes.
If you omit them, remove the `icons` and `action.default_icon` entries from
`manifest.json` or Chrome will warn on load.
